# Lumesearch - AI Build Blueprint (Intelligent Search)

This repository contains a modern, AI-enhanced search interface designed for rapid information retrieval and data synthesis.

## Goal
To provide a unified search experience that combines traditional search capabilities with AI-driven insights and summarization.

## Tech Stack
- **Frontend:** Vanilla JS, CSS3, HTML5.
- **Styling:** Custom CSS with a focus on dark mode and readability.
- **Logic:** Modular JavaScript for search query processing and UI updates.
- **Integration:** Hooks for AI API integration (Gemini/OpenAI) for query expansion and result summarization.

## AI Guidelines
1. Maintain the "Lume" aesthetic: minimal, glowing (luminescent) UI elements, and high contrast.
2. When improving search logic, prioritize client-side filtering and debouncing for a fluid experience.
3. Ensure all utility functions in \utils.js\ are pure and well-documented.
4. Implement a robust error handling system for API failures in \script.js\.
